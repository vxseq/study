## 1. Цель работы

Разработать небольшое приложение, в котором руководитель может смотреть статусы проектов, а аналитик — создавать задачи, назначать исполнителей и устанавливать сроки.

## 2. Что было сделано

Я сделал серверную часть на Python с использованием FastAPI и SQLAlchemy. Для хранения проектов, задач и участников использовал базу данных SQLite. Для просмотра проектов и работы с задачами сделал простую веб-страницу на HTML, CSS и JavaScript.

В приложении можно:

1. Создавать, просматривать, изменять и удалять проекты.
2. Добавлять участников команды.
3. Создавать задачи, назначать исполнителя и срок, изменять статус и удалять задачи.
4. Просматривать статус проекта — «В сроке», «Есть риски» или «Блокер».
5. Смотреть документацию API в Swagger.

Статус рассчитывается автоматически. Если есть задача со статусом «Блокер», весь проект становится красным. Если блокеров нет, но есть невыполненная просроченная задача, статус становится жёлтым. Иначе он зелёный.

## 3. Использованные технологии

- Python и FastAPI — сервер и API.
- SQLAlchemy и SQLite — работа с базой данных.
- Pydantic — проверка запросов.
- HTML, CSS, JavaScript — внешний вид сайта и кнопки.
- pytest и FastAPI TestClient — автоматические тесты.
- Docker — запуск приложения в контейнере.
- Ruff, Black и GitHub Actions — проверка кода.

## 4. Структура приложения

- `models.py` — таблицы базы данных.
- `schemas.py` — схемы входящих и исходящих данных.
- `routers/` — обработчики запросов проектов, задач и пользователей.
- `services.py` — проверка дедлайнов и расчёт статуса.
- `static/` — интерфейс сайта.
- `tests/` — автотесты.
- `migrations/` — создание таблиц SQLite.

## 5. Проверка работы

На этапе подготовки проекта локально запущено **17 автоматических тестов**, все прошли успешно (`17 passed`). Тесты проверяют создание и изменение проектов, работу задач, существование пользователей и все три цвета статуса. Проверяется также, что после изменения или удаления задачи статус пересчитывается.

Для отдельной проверки можно использовать Swagger по адресу `http://127.0.0.1:8000/docs`.
