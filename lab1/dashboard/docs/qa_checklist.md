# Чек-лист проверки дашборда

- [ ] Открывается главная страница `/`.
- [ ] Можно создать проект, он появляется в списке.
- [ ] Можно отредактировать название и описание проекта.
- [ ] Можно добавить участника.
- [ ] Можно создать задачу для существующего проекта.
- [ ] Можно назначить исполнителя и дедлайн.
- [ ] Можно изменить статус задачи на «Готово» и «Блокер».
- [ ] Проект без проблем — зелёный.
- [ ] Просроченная незавершённая задача — жёлтый.
- [ ] Задача «Блокер» — красный, даже если есть просрочка.
- [ ] После удаления блокирующей задачи статус пересчитывается.
- [ ] После удаления проекта удаляются его задачи.
- [ ] Создание задачи для несуществующего проекта даёт 404.
- [ ] Нельзя создать задачу с неизвестным статусом (422).
- [ ] На телефоне можно открыть список проектов и задач.
- [ ] `python -m pytest -q` проходит без ошибок.
