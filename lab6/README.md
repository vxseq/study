# Лабораторная работа № 6

Вариант 11, продвинутый уровень. «Линия» — учебный сайт-визитка архитектора.

Откройте `index.html` в браузере. Установка зависимостей не требуется.

- `index.html` — шапка, описание бюро, карточки проектов и подвал.
- `css/style.css` — стили БЭМ, CSS Grid, Flexbox и адаптивные правила.
- `img/` — иллюстрации трёх архитектурных концепций.

Базовая раскладка рассчитана на телефон. С 768 px карточки занимают две колонки, с 1100 px — три. Шапка оформлена через Flexbox, а сетка проектов — через CSS Grid. Анимация отключается при включённой системной настройке уменьшения движения.
